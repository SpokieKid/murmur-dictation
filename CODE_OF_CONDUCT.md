# Code of Conduct

Murmur is committed to a welcoming, respectful, and harassment-free community.

Be kind, assume good intent, give constructive technical feedback, and respect
differences in background, identity, experience, and viewpoint. Harassment,
personal attacks, discrimination, doxxing, and sustained disruption are not
acceptable in project spaces.

Maintainers may edit, hide, or remove contributions that violate these standards
and may temporarily or permanently restrict participation when necessary. Report
sensitive conduct concerns privately through the repository owner's GitHub profile.
Maintainers will handle reports with discretion and fairness.
