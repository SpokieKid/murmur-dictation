# Security Policy

## Supported version

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting / Security Advisory flow for this repository.
Include reproduction steps, affected macOS version, and the expected impact.

Do not include API keys, transcripts, audio recordings, or other personal data in
reports. The maintainer will acknowledge a complete report as soon as practical
and coordinate disclosure after a fix is available.
