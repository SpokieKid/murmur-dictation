# Murmur 小红书互动演示

这个页面用于录制 9:16 小红书视频，完整演示：

1. 普通语音输入只能转写自己通过麦克风说的话。
2. 开启 Murmur 的“电脑声音”后，线上会议中同事的发言也能转成文字。
3. 一段音频仍在处理时，可以继续按 FN 说下一段；结果会按说话顺序进入输入框。

## 使用方式

直接双击 `index.html` 即可离线运行。也可以在这个目录启动任意静态文件服务器。

- 点击右上角全屏按钮，进入干净的 9:16 录制画面。
- 点击“播放完整演示”，自动播放约 18 秒的完整流程。
- 点击任意参会者头像，可以手动触发一句发言。
- 点击“电脑声音”开关，可以展示开启和关闭状态。
- 按住页面里的“FN”按钮，可以手动模拟自己的语音输入。

页面不依赖网络、外部字体或图片素材，离线录屏也能保持完整效果。
