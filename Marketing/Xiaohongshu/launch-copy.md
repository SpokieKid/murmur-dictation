# 小红书开源发布

## 推荐标题

不用等转写，线上开会时同事的话也能变文字

## 正文

前阵子把 Murmur 给朋友们试用，大家反复提到的不是“识别率又高了多少”，而是两个很朴素、但用了就回不去的功能：

1️⃣ 说完一段，不用等

普通语音输入在转录、润色时，你往往只能看着它转圈。Murmur 处理中依然可以继续按 Fn 说下一段；几段内容并行处理，最后仍会严格按照你说话的顺序输入。

灵感不用排队，人也不用被进度条打断。

2️⃣ 电脑里的声音，也能转成文字

线上会议时，不只有你在说话。Murmur 可以同时收录麦克风和 Mac 正在播放的声音，把你和对方的发言一起交给语音识别。听歌时，从菜单栏取消勾选「收录电脑声音」就好。

这里我特意不用“监听”这个词：它只会在你主动开始听写时收录声音，不保存屏幕画面；代码现在也是完全公开的。

今天，Murmur 正式开源。

- macOS 13+
- 简体中文 / English，可在应用内即时切换
- 用户自行配置 API Key，支持 OpenAI 兼容接口与阿里云百炼
- MIT License

GitHub：<https://github.com/SpokieKid/Murmur>

如果这两个功能也正好解决了你的痛点，欢迎试用、提 Issue，或者顺手点一颗 Star ⭐️

## 置顶评论（可选）

目前先发布源码版，安装需要在 Mac 上构建；公开仓库里有完整步骤。电脑声音功能使用的是 macOS 官方 ScreenCaptureKit，只在主动听写期间工作，并且不保存屏幕画面。
