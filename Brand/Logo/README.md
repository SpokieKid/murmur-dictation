# Murmur Logo System

## 核心概念

**两路声音，一路成文。**

- 上方朱红声流代表使用者通过麦克风说的话。
- 下方近黑声流代表线上会议等场景中的电脑声音。
- 两条线同时进入中心，表达 Murmur 可以并行处理多个音频来源。
- 汇合后向右延伸的单一线条，表达转写内容最终按次序进入输入框。
- 圆角线端延续产品中柔和、持续的声音波形语言，同时避开常见的麦克风图标。

## 品牌色

- Paper：`#F2EEE6`
- Ink：`#151618`
- Voice：`#F03A2F`

这套颜色来自 Murmur 小红书开源物料：温暖米白作为大面积底色，近黑承担信息，朱红只强调声音和动作。

## 文件

- `murmur-mark.svg`：首选双色图形标，透明背景。
- `murmur-wordmark.svg`：横版图形标与 Murmur 字标组合。
- `murmur-app-icon.svg`：带米白底色的 1024 × 1024 App Icon 母版。
- `murmur-app-icon.png`：可直接预览和投放的 1024 × 1024 App Icon。
- `murmur-mark-512.png`：透明背景的 512 × 512 图形标。
- `murmur-mark-monochrome.svg`：浅色背景使用的单色版本。
- `murmur-mark-white.svg`：深色或朱红背景使用的反白版本。
- `preview.html`：完整设计概念与应用预览。

## 使用规则

- 首选使用双色标志，并保留至少相当于线条粗细两倍的四周留白。
- 小于 20 px 时使用单色版本，避免双色交界在低分辨率下变脏。
- 不拉伸、不旋转、不增加描边，也不要改变红黑两条声流的顺序。
- App Icon 中的投影只属于图标底板，不应添加到透明图形标上。
